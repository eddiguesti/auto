## Executive Summary

**Easy Memoir** is an AI-powered autobiography platform that helps seniors and families preserve life stories through natural conversation, transforming memories into beautifully written, printed books.

### The Opportunity

- 12 million people aged 65+ in the UK
- Growing demand for meaningful, personalised gifts
- No writing skills required - just talk
- Emotional value far exceeds production cost

### Business Model

Multiple channel options under consideration:

- **Option A:** Direct website sales (highest margin, requires traffic generation)
- **Option B:** Amazon + website hybrid (built-in traffic, lower margin)
- **Option C:** Digital-only (lowest risk, fastest launch)

Core offering: Gift boxes (£99) or digital access that includes the platform and a printed hardcover book. Revenue expands through upsells (extra book copies, audiobooks).

## Product Overview

### What is Easy Memoir?

Easy Memoir is a web-based platform that guides users through creating their autobiography using AI-powered voice interviews. The platform:

1. **Captures stories** through natural conversation (voice or text)
2. **Organises memories** into 10+ life chapters with 70+ guided questions
3. **Enhances writing** using AI to transform casual speech into polished prose
4. **Builds a memory graph** connecting people, places, and events
5. **Produces tangible outputs** - printed hardcover books, eBooks, and audiobooks

### Core Technology

| Component       | Technology                                        |
| --------------- | ------------------------------------------------- |
| Frontend        | React, Vite, TailwindCSS                          |
| Backend         | Node.js, Express, PostgreSQL                      |
| AI Engine       | Grok (xAI) for interviews and content enhancement |
| Voice           | xAI Realtime API, Fish.audio for audiobooks       |
| Payments        | Stripe                                            |
| Print-on-Demand | Lulu API (Amazon KDP optional future)             |
| Hosting         | Render.io                                         |

### Product Status

- **Stage:** Beta / MVP with production features
- **Domain:** easymemoir.co.uk
- **Current Users:** Early adopter phase (first 100 free)

## Go-to-Market Strategy

### Channel Options Comparison

#### Option A: Direct Website Only

| Pros                                 | Cons                                |
| ------------------------------------ | ----------------------------------- |
| 97% revenue retained (3% Stripe fee) | No built-in traffic                 |
| Full customer data ownership         | Must drive all traffic via paid ads |
| Complete brand control               | Lower trust for new visitors        |
| Flexible pricing                     | Self-managed fulfillment            |

**Net per £99 sale: £91**

#### Option B: Amazon + Website Hybrid

| Pros                        | Cons                    |
| --------------------------- | ----------------------- |
| Amazon's massive traffic    | 15-20% Amazon fees      |
| Prime badge = instant trust | Limited customer data   |
| FBA handles fulfillment     | Account suspension risk |

**Net per £99 sale: £76 (Amazon) / £91 (website)**

#### Option C: Digital Only

| Pros              | Cons                            |
| ----------------- | ------------------------------- |
| Zero inventory    | No tangible gift                |
| Instant delivery  | Harder to justify premium price |
| 95%+ margins      | Miss gift-buying market         |
| Fastest to launch | Less differentiated             |

**Net per £49-89 sale: £45-85**

### Recommended Approach: Phased Rollout

**Phase 1:** Launch digital-only on website to validate demand
**Phase 2:** Add physical gift box if digital converts
**Phase 3:** Expand to Amazon if gift box proves concept

## Operations Plan

### Fulfillment Strategy

**Gift Box Fulfillment (if physical boxes):**

- Option A: Self-fulfillment from home/3PL
- Option B: Amazon FBA (if selling on Amazon)
- Initial inventory: 50-100 units
- Reorder point: 20-30 units remaining

**Book Fulfillment:**

- Print-on-demand via Lulu API (current)
- Future option: Amazon KDP for lower costs
- Triggered when user marks memoir "complete"

### Customer Journey

**Physical Gift Box Path:**

```
1. Gift purchaser buys box (website or Amazon)
              ↓
2. Box ships to recipient (or purchaser to wrap)
              ↓
3. Recipient opens box, scans QR code
              ↓
4. Personalised onboarding: "Welcome! [Name] gave you this gift"
              ↓
5. Guided memoir creation (weeks/months)
              ↓
6. AI polishes content, user reviews
              ↓
7. Hardcover book prints and ships automatically
              ↓
8. Family orders extra copies (upsell)
              ↓
9. Referral drives new purchases
```

**Digital-Only Path:**

```
1. Customer purchases digital access on website
              ↓
2. Instant account activation
              ↓
3. Guided memoir creation (weeks/months)
              ↓
4. AI polishes content, user reviews
              ↓
5. Customer orders printed book (optional)
              ↓
6. Upsell extra copies, audiobook
```

## Risk Analysis

### Key Risks and Mitigations

| Risk                       | Likelihood | Impact   | Mitigation                                      |
| -------------------------- | ---------- | -------- | ----------------------------------------------- |
| Low initial sales          | Medium     | High     | Pre-launch list reduces cold start              |
| Amazon account suspension  | Low        | Critical | Only if using Amazon; diversify to website      |
| AI quality issues          | Low        | Medium   | Human review before print                       |
| High customer support load | Medium     | Medium   | Self-service guides, video tutorials            |
| Competitor entry           | Medium     | Low      | First-mover advantage, voice differentiation    |
| Seasonal dependency        | High       | Medium   | Build recurring revenue, expand occasions       |
| Inventory risk             | Medium     | Medium   | Start small (50 units), validate before scaling |

### Contingency Plans

**If sales are slow (< 20 in first month):**

- Increase ad spend on best-performing creative
- Add lower price point option (£59 digital-only)
- Partner with retirement community for bulk trial

**If costs exceed projections:**

- Reduce box contents to essentials
- Shift more sales to direct website (avoid Amazon fees)
- Delay audiobook feature development
